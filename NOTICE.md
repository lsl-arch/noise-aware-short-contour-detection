# Third-Party Assets and Attribution

The repository contains the experiment implementation and a local DexiNed model-definition file used by the archived experiment. The BSDS500 dataset, OpenCV Structured Forests weights, and DexiNed checkpoint are not included; they must be obtained from their respective upstream sources. Their licenses and redistribution terms remain separate from this repository. Users are responsible for reviewing those terms before downloading or redistributing third-party assets.

The experiment uses OpenCV's `ximgproc` Structured Edge Detection implementation and the model distributed through `opencv_extra`, as well as the DexiNed implementation/checkpoint identified in the README and frozen protocol.
