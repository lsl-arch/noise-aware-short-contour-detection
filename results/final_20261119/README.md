# Archived Final Run

This directory contains the compact evidence from the frozen run completed on 2026-11-19. It omits image-level prediction archives to keep the repository lightweight. The full per-image metrics are retained in `per_image.json`; aggregate tables can be reconstructed from those records under the protocol in `protocol.json`.

`environment.json` has been sanitized to remove the original machine's absolute Python executable path. All scientific run metadata, versions, source hashes, and verification status are preserved in the remaining files.
